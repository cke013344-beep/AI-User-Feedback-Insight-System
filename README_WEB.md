# Feedback Studio：个人本地使用版

## 第一次打开

1. 在 Finder 中打开本文件所在的 `outputs` 文件夹。
2. 双击 **启动反馈分析.command**。
3. 第一次会在终端提示粘贴有效的 OpenRouter 密钥。输入不显示，粘贴后按回车。直接按回车可先使用关键词分类。
4. 浏览器自动打开本地网页。保持启动窗口打开；关闭服务时在该窗口按 `Ctrl+C`。

不需要安装额外 Python 包。使用电脑上已有的 Python 3.9 或以上版本。启动入口使用可用的本地端口，网址在启动窗口中显示；再次双击会尝试打开已运行的网页。

## 单条评论

粘贴英文 App 评论（最多 2000 字符），点击「开始 AI 分析」。每次调用一次模型，自动保存。详情中并排展示：

- 关键词规则的四类分类。
- AI 的大类、十类固定主题、严重程度、用户需求、逐字引用。

「仅运行关键词分类」不会调用模型，且只有大类结果，不提供其他四个字段。

## CSV 批量分析

切换到「CSV 批量导入」。UTF-8 文件必须有 `review` 列，可带 `review_id`。最多 500 条、2 MB，每条不超过 2000 字符。页面可下载两个**合成格式示例**组成的 CSV；它不是评估数据。

选择文件后先预览：显示有效数量及未导入的错误行。上传不调用模型。点击开始按钮并确认数量后，每条调用一次，按顺序处理。只有一个 AI 任务可以同时运行，避免多批任务竞争或重复消耗。关键词批量分类也可独立运行。

- **暂停：**等当前请求结束并保存，再停止发下一条。
- **继续待处理项：**跳过已有成功、失败和无效结果，只分析尚未处理的评论。
- **重试失败 / 中断项：**明确确认后再发请求，原来的请求记录保留。待处理项也会继续分析。
- **服务意外关闭：**重启后恢复历史，暂停未完成任务；无法确定是否已完成的请求标为中断，不自动重发。模型服务可能已收费但结果未保存，重试可能再次收费。

格式错误、未知主题或引用不逐字匹配时，该条标为输出无效，不自动“修正”为成功。原始响应在详情中可查看。

## 统计、筛选和历史

当前分析的面板展示大类、主题、严重程度分布，高严重程度数量，以及已保存的累计输入/输出 Token。百分比只以有效结果为分母，失败项不混入分布。关键词与 AI 分类不一致的数量只表示分歧，不等于错误率。Token 包含重试记录，但无法确定的请求计费用量需以服务商记录为准；不宣称网页显示的是账单金额。

列表可按大类、主题、严重程度、状态和文本筛选。点击行查看英文原文、需求、证据和原始响应。统计面板始终对应整次分析，不随列表筛选改变。左侧历史可重新打开已有分析记录。没有跨历史的全局报表；每次分析作为一份独立记录。

## 保存和导出

历史自动保存到 `outputs/local_data/runs/`，一份分析一个 JSON 文件。刷新页面、关闭浏览器不会删除记录；停止服务后可在下次启动继续查看。

CSV 和 JSON 导出保存**当前整次分析**，包括失败和待处理行，不仅是筛选后的行。CSV 包含原文、关键词结果、AI 字段、状态、错误和累计 Token；JSON 另包含完整请求历史、原始响应及模型/提示词标识。CSV 为避免电子表格把评论当公式执行，会给以 `= + - @` 等开头的字符串添加单引号；JSON 保留存储文本。

CSV 导入会去掉评论前后的空白，分析和引用校验以去除这些空白后的评论为准。

## 密钥与连接

第一次输入的密钥存于本机 `outputs/local_data/.openrouter_key`，文件只允许当前用户读写。**它是本机明文配置，不是加密保险箱；不要分享或提交整个 local_data 文件夹。** 网页不展示密钥，不把它存在浏览器或结果文件中。默认调用 OpenRouter 的 `openai/gpt-4o-mini`，评论会发送给模型服务；历史结果保存在本机。

如需更换密钥，先停止服务；在终端进入 outputs 后执行下面命令，然后重新双击启动入口：

```bash
read -s "feedback_new_key?请粘贴新密钥: "; echo
(umask 077; printf '%s' "$feedback_new_key" > local_data/.openrouter_key)
unset feedback_new_key
```

这个版本默认仅本机访问。需要同 Wi-Fi 分享时仍可运行 `python3 web_app.py --host 0.0.0.0 --provider openrouter`，终端会显示访问码。拥有访问码的人能读取此工作区历史、使用 API 余额；本次个人版本不要求局域网分享或公网部署。

## 与课程实验的关系

网页继续使用冻结的 V5 提示词和原关键词规则。网页历史不改写任何课程评估 CSV、模型输出或参考答案。已有评估结果不能作为随意输入的新评论的实时准确率。

直接双击 `index.html` 仍是离线预览：只能使用单条关键词分类，不保存记录。完整功能请通过启动入口打开。

实现已完成；本次未运行新的模型评估、付费 API 调用或自动化功能测试。首次实际使用的运行情况仍需以你电脑上的启动和操作为准。
