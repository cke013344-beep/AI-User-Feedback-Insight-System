What the errors taught me

H011

A valid quote can support a wrong story.

The model added a link between uninstalling and paying that the review never stated. Formatting passed; need fidelity failed.

H018

Exact evidence means exact text.

The model changed “If” to “if”. The case-sensitive quote check rejected the output, even though its category was reasonable.

A small system, with explicit trade-offs.

Own the workflow

Python + HTML, fixed labels and deterministic checks. Easier to inspect; local setup and maintenance are required.

Rent the model

GPT-4o-mini via OpenRouter interprets indirect wording. Each review adds provider cost and network dependency.

Keep the reviewer

Original text and evidence support manual decisions. No measured time-saving or production-reliability claim.
